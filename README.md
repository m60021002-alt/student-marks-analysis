# Student Marks Analysis

A Python project using Pandas to analyze student marks from a CSV file.

## Features
- Calculate average, highest, and lowest marks
- Subject-wise average marks (Math, Science, English)
- Pass/Fail count based on passing marks (40)

## Technologies Used
- Python
- Pandas
- NumPy (used internally by Pandas)

## How to Run
1. Install pandas: `pip install pandas`
2. Run the program: `python student_analysis.py`
